TITLE:
[Shader] Edge Chroma Ward — image-driven colored-fringe cleanup

POST:
[b]Edge Chroma Ward[/b]
[i]by prutrescor[/i]

Edge Chroma Ward is a color-only ReShade effect for removing thin colored rims from high-contrast edges. I built it after observing narrow magenta edge contamination in stationary captures that could become more visible after a larger effect stack. The same detector can be tuned for cyan, green, red, blue, and yellow fringes.

This is not a global desaturation pass and it does not require depth or game motion vectors. Correction is allowed only where the image provides three pieces of spatial evidence:

[list]
[*]a local luminance edge;
[*]a color excess in one of six opponent color families; and
[*]a narrow-band response that does not persist into the wider neighborhood.
[/list]

The last test is the important restraint. [b]Protect Persistent Color[/b] reduces correction when a color continues across nearby pixels, which helps distinguish a one-pixel fringe from an actual purple flower, colored surface, or light. The replacement candidate comes from the local neighborhood, then the center pixel's luminance is reapplied so the ward does not simply blur away the edge's brightness structure.

[b]Optional minute temporal guard[/b]

The effect remains spatial by default. The optional guard does not blend previous-frame image color. It briefly carries a small, rapidly decaying part of the previous [i]removal mask[/i] when slight image movement temporarily occludes the current spatial detection. A small cross-shaped history search can follow a minute pixel shift, while source-color comparison rejects unrelated history and larger frame changes. It is intended as a conservative continuity aid, not a general temporal filter.

[b]Suggested setup order[/b]

Start around a one-pixel radius and inspect the masks before increasing strength. Tune only the color families you can actually see. Raise [b]Protect Persistent Color[/b] before reducing the detector thresholds.

Place Edge Chroma Ward before strong sharpening, clarity, saturation, or bloom passes that may enlarge an existing game-rendered fringe. If one later shader creates a new rim, move the ward immediately after that shader and inspect the masks again.
